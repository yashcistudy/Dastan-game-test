# کوه‌پیمایی دستان

A short Persian feedback game for the Dastan honey brand: seven quick "peaks" (a 5-second logo read, an A/B choice, five like/dislike cards, three feeling words, the tallest honey, a gift-box price, and a last comment). Answers go to Formspree; if sending fails, players can copy the summary or share it on Telegram.

Static site: `index.html` + `fonts/`. The Formspree endpoint is set at the top of the script in `index.html`.
